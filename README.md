# Лабораторные работы (Python + Django)

Репозиторий содержит лабораторные работы №1–7 по Python 3 и Django.

## Структура

```
.
├── lab01/          # Lab 1: Python + старт Django
├── lab02/          # Lab 2: шаблоны и статика
├── lab03/          # Lab 3: модель Article
├── lab04/          # Lab 4: страница статьи
├── lab05/          # Lab 5: форма создания поста
├── lab06/          # Lab 6: регистрация и вход
├── lab07/          # Lab 7: JavaScript
├── manage.py       # manage.py проекта Lab 1
├── requirements.txt
└── README.md
```

## Общие требования

- Python 3.7+ (проверено на 3.12)
- Django 4.2+ / 5.x / 6.x

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Подробный запуск и дерево файлов — в `README.md` внутри каждой папки `lab0N`.
